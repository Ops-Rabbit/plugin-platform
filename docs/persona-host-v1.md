# Persona host helpers v1

SDK 0.25.0 types an optional `context.host` service for the reviewed `data_insight_sql` provider. Its manifest declares `"personaHost": { "schemaVersion": "1" }` under `capabilities`. The declaration is validated by the SDK and published manifest JSON Schema. It does not grant access by itself: hosts that support this contract expose the methods only for the reviewed provider and enforce the signed-in tenant, role, current group state, dashboard authorization, and policy audit at each call. Older hosts and other plugins see no service. A plugin must check method presence before use.

| Method                                                         | Result                                           | Host authority                                                                                                                    |
| -------------------------------------------------------------- | ------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------- |
| `listTenantGroups()`                                           | `{ id, name }[]` of active local and SCIM groups | Signed-in tenant operator or admin; SCIM groups require an enabled identity-provider connection.                                  |
| `listTenantUsers()`                                            | `{ id, name, email, role }[]`                    | Signed-in tenant admin; membership and effective tenant role come from the host.                                                  |
| `ensurePersonaDashboards({ templateIds, moduleKey, grants? })` | `{ templateId, dashboardId }[]`                  | Signed-in tenant admin; materializes or refreshes host dashboards and applies group policy mappings with host audit and rollback. |

The [executable reference](../packages/plugin-sdk/test/fixtures/persona-host-reference.ts) checks availability, uses the active-group directory, and asks the host to materialize a dashboard. Its [test](../packages/plugin-sdk/test/persona-host-reference.test.ts) covers successful use and missing capability/group failure. The helper does not expose host database tables or provider connection secrets. The host owns dashboard and policy retention, deletion, revocation, and audit. This contract adds no plugin data store or copy.

The `forms-insights` starter demonstrates separate, caller-scoped Data Insight authorization; it does not request persona helpers because generated plugin ids are not the reviewed provider. External `data_insight_sql` implementations can use this contract after SDK 0.25.0 is published and a compatible host release is deployed. Check the optional service at runtime even when the manifest declares it.
